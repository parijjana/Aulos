## Technical Findings
- **Background Parsing**: Moving `RssFeed.parse` to an isolate via `compute()` is mandatory for feeds >1MB to prevent frame drops.
- **Isolate-Safe States**: Using a Map of `NavigationState` keyed by mode is the most efficient way to prevent state leakage in a multi-hub architecture.
- **Windows Unicode**: `FileStreamSource` remains the only verified way to handle special characters (like `꞉`) in filenames on Windows.
